# AD — proyecto en Snap!

Proyecto visual desarrollado con Snap! y publicado originalmente en la plataforma de UC Berkeley.

## Abrir el proyecto

1. Abre [Snap!](https://snap.berkeley.edu/snap/snap.html).
2. Selecciona **File → Import**.
3. Importa el archivo `AD.xml` incluido en este repositorio.

También puedes consultar la [versión publicada](https://snap.berkeley.edu/project?username=eduardo336&projectname=AD).

El archivo XML contiene el código, los sprites y los recursos necesarios para ejecutar el proyecto.
